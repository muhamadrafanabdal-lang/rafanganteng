01 — Materi

Alat & Bahan

Beberapa alat utama yang diperlukan untuk membuat kabel LAN dan melakukan koneksi antar dua komputer.

🧵

Kabel UTP

Kabel jaringan yang digunakan sebagai media penghantar data antar perangkat.

🔌

RJ45

Konektor yang dipasang pada ujung kabel UTP agar dapat terhubung ke port Ethernet.

✂️

Tang Crimping

Digunakan untuk memasukkan dan mengunci kabel UTP ke dalam konektor RJ45.

🧪

LAN Tester

Digunakan untuk memeriksa apakah susunan kabel LAN sudah terhubung dengan benar.

03 — Praktik

Langkah Merangkai Kabel LAN

Ikuti langkah berikut secara berurutan agar konektor RJ45 terpasang dengan benar.

01

Kupas Kabel

Kupas bagian luar kabel UTP menggunakan stripper atau alat pengupas kabel.

02

Pisahkan Kabel

Pisahkan pasangan kabel kecil yang berada di dalam kabel UTP.

03

Susun Warna

Susun kabel berdasarkan standar warna yang digunakan, misalnya T568A dan T568B.

04

Luruskan Kabel

Luruskan semua kabel agar mudah dimasukkan ke konektor RJ45.

05

Potong Rata

Potong ujung kabel menggunakan tang crimping agar panjang kabel sama.

06

Masukkan RJ45

Masukkan kedelapan kabel ke dalam RJ45 sesuai urutan warna.

07

Crimping

Tekan konektor RJ45 menggunakan tang crimping sampai terkunci dengan kuat.

08

Uji LAN Tester

Hubungkan kabel ke LAN tester dan periksa indikator pin 1 sampai 8.

09

Kabel Siap

Jika hasil tester benar, kabel LAN siap digunakan untuk koneksi antar perangkat.

04 — Network

Hubungkan 2 Laptop

Hubungkan kedua laptop menggunakan kabel LAN crossover, kemudian atur alamat IP secara manual.

💻 Laptop 1

IP Address 10.10.10.1
Subnet Mask 255.0.0.0
Gateway Kosong

💻 Laptop 2

IP Address 10.10.10.2
Subnet Mask 255.0.0.0
Gateway Kosong

⚙️ Cara Setting IP

Control Panel → Network and Internet → Network and Sharing Center → Change adapter settings → Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4).

Win + R → cmd → ping 10.10.10.2
05 — File Sharing

Sharing File Antar Laptop

Setelah kedua laptop terhubung, file dapat dibagikan melalui jaringan LAN.

STEP 01

Pilih Folder

Klik kanan folder yang ingin dibagikan, kemudian pilih Properties.

STEP 02

Advanced Sharing

Pilih menu Sharing → Advanced Sharing, lalu centang Share this folder.

STEP 03

Aktifkan Sharing

Aktifkan Network Discovery dan File Sharing pada pengaturan jaringan Windows.

STEP 04

Akses Dari Laptop 2

Tekan Windows + R, lalu masukkan alamat:

\\10.10.10.1
